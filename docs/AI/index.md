## 🔗 Взаимосвязь технологий

Эмбеддинги, LLM и MCP работают вместе в современной AI-экосистеме:

1. **Эмбеддинги** преобразуют данные в числовые векторы для поиска и анализа
2. **LLM** используют эмбеддинги для понимания и генерации текста
3. **MCP** предоставляет LLM доступ к реальным инструментам и данным
4. **Skills** задают агенту пошаговые сценарии и критерии для конкретных задач (поведение поверх LLM и инструментов)
5. Вместе они создают мощные AI-приложения с пониманием контекста и возможностью взаимодействия с внешними системами

### Схема взаимодействия

```
            │
            ▼
┌─────────────────────────────────────┐

└───────────┬─────────────────────────┘
            │
            ▼

│         MCP                         │

└─────────────────────────────────────┘
```

## 🚀 Быстрый старт

1. **Начните с эмбеддингов** — это основа для понимания работы AI с данными
2. **Изучите LLM** — узнайте, как большие языковые модели обрабатывают текст
3. **Разберитесь с MCP** — поймите, как расширить возможности LLM через протоколы
4. **Изучите Skills** — настройте поведение агента в Cursor через скиллы для повторяемых задач
