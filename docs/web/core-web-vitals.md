# Core Web Vitals

Core Web Vitals — набор метрик Google для оценки пользовательского опыта на веб-страницах. Они напрямую связаны с [критическим путём рендеринга](./critical-rendering-path).

---

## Три основные метрики

### LCP (Largest Contentful Paint)

Время до отрисовки **самого крупного видимого элемента** (изображение, блок текста, видео).

- **Хорошо:** ≤ 2.5 с
- **Требует улучшения:** 2.5–4 с
- **Плохо:** > 4 с

**Как улучшить:**
- Оптимизировать серверный ответ (TTFB)
- Предзагрузка критических ресурсов (`<link rel="preload">`)
- SSR / Streaming для раннего контента
- Оптимизация изображений (WebP, размеры, lazy load для некритичных)

### INP (Interaction to Next Paint)

Задержка между действием пользователя и следующей отрисовкой. Заменил FID как метрику отзывчивости.

- **Хорошо:** ≤ 200 мс
- **Требует улучшения:** 200–500 мс
- **Плохо:** > 500 мс

**Как улучшить:**
- Разбивать длинные задачи (`scheduler.yield`, `requestIdleCallback`)
- Code splitting — меньше JS на старте
- Мемоизация только там, где нужно ([оптимизация React](../react/optimization))

### CLS (Cumulative Layout Shift)

Суммарный сдвиг макета — когда элементы «прыгают» при загрузке.

- **Хорошо:** ≤ 0.1
- **Требует улучшения:** 0.1–0.25
- **Плохо:** > 0.25

**Как улучшить:**
- Указывать `width`/`height` для изображений и видео
- Резервировать место под динамический контент (skeleton)
- Не вставлять контент над уже отрисованным без резерва

---

## Связь с CRP

| Метрика | Связь с CRP |
|---------|-------------|
| LCP | Блокирующий CSS/JS, размер DOM, TTFB |
| INP | Объём и время выполнения JS |
| CLS | Порядок загрузки ресурсов, отсутствие размеров |

Паттерны оптимизации CRP (SSR, Streaming, Hydration, Code Splitting, App Shell, Skeletons) описаны в [статье о критическом пути](./critical-rendering-path).

---

## Измерение

- **Chrome DevTools** → Performance, Lighthouse
- **PageSpeed Insights** — полевые и лабораторные данные
- **web-vitals** (npm) — отправка метрик в аналитику

```javascript
import { onLCP, onINP, onCLS } from 'web-vitals';

onLCP(console.log);
onINP(console.log);
onCLS(console.log);
```
