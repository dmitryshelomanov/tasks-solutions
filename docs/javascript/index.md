# JavaScript

Материалы по JavaScript: основы языка, продвинутые концепции, вопросы с собеседований и практические примеры.

## 📚 Содержание

### Основы языка

- **[Объекты](./objects.md)** — работа с объектами в JavaScript, ссылочная природа, копирование
- **[Числа](./numbers.md)** — работа с числами, бинарные числа, BigInt и операции с большими числами
- **[Контекст, область видимости и переменные](./context-scope-variables.md)** — scope, контекст выполнения (this), arrow functions, bind
- **[Event Loop](./event-loop.md)** — асинхронность в JavaScript, промисы, микротаски, очередь выполнения
- **[Прототипы](./prototypes.md)** — прототипное наследование, `__proto__` и `prototype`, цепочка прототипов
- **[Методы классов](./class-methods.md)** — стрелочные функции vs обычные функции, наследование, super, instanceof

### Практические материалы

- **[Вопросы с собеседований](./interview-questions.md)** — Популярные вопросы с подробными ответами и примерами кода для подготовки к техническим собеседованиям:
  - Promise, async/await и обработка ошибок
  - Hoisting и временная мертвая зона (TDZ)
  - Типы данных, приведение типов и сравнение
  - Замыкания в циклах
  - Деструктуризация, spread и rest операторы
  - Модули ES6, import/export и область видимости

- **[package.json](./package-json.md)** — основные поля package.json и их назначение:
  - name, version, description, type
  - main, module, types, exports
  - files, scripts, dependencies
  - devDependencies, peerDependencies
  - engines, repository, homepage
